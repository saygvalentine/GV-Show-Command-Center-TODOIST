#1 - Task Filter, Sort & Group in Show Detail
What & Why
The task list in Show Detail grows long for busy shows. Users need to quickly focus on specific categories (e.g., only Fire Marshal tasks), reorder by different criteria, and optionally view tasks grouped by category rather than by urgency status. All changes are purely frontend — no API changes needed.

Done looks like
A compact toolbar sits between the "Tasks" heading and the task list with three controls: Filter, Sort, and Group
Filter: a dropdown multi-select for category ("All", "Show Bucket", "Fire Marshal", "ID Sign", "Warehouse Manifest", "Vehicle Spotting", "Electrical"). Active filters show as dismissible chips next to the dropdown. Filtering applies across all groups.
Sort: a dropdown with options — Due Date (default, ascending), Due Date (descending), Name A→Z, Category
Group by: a toggle/dropdown with two modes:
Status (default): current behavior — Overdue / Upcoming / Completed sections
Category: one collapsible section per category (alphabetical), tasks within each sorted by the active sort. An "Uncategorized" section catches tasks with no category.
Completed tasks collapsible section still appears at the bottom in Status grouping; in Category grouping, completed tasks are visually dimmed within their category section rather than separated
Toolbar state is local (not persisted) — resets on page navigation
Controls are compact and unobtrusive; toolbar disappears gracefully if there are no tasks
Out of scope
Persisting filter/sort/group preferences to localStorage or the server
Filtering by date range
Searching tasks by name (separate feature)
Any changes to the e-blasts tab
Steps
Add toolbar UI — Add a row of controls (Filter, Sort, Group) above the task list. Use existing shadcn Select and Badge components; no new dependencies. Keep it visually compact.
Wire filter logic — Apply the active category filter to the task array before grouping, hiding tasks whose category doesn't match any selected filter. "All" clears the filter.
Wire sort logic — Apply the selected sort to each section's task array within the existing useMemo grouping. Due Date ascending is the default (preserving current behavior).
Implement Category grouping mode — When Group = Category, replace the overdue/upcoming/completed sections with one collapsible section per category. Within each section, completed tasks are dimmed in-place. Sections start expanded.
